V920 - page sweep engine (m_buffer + m_size)

Both forge dimensions, used together for the first time: the read is lineWidth = *(m_buffer + (m_size-1)*400 + 48) with m_buffer (64-bit) and m_size (32-bit) both in our AB, JS-rewritable between reads. The engine: random 0x4000-aligned candidate in the libWebKit range [0x800000000, 0x900000000) -> probe its first page at 400B steps (41 probes = the page's content) -> mapped = 40 bytes leaked per probe, continue to the next page -> unmapped = crash = the region boundary (maps memory) -> next candidate. Everything resumes across reloads automatically. The first surviving probe = the first leaked memory bytes on 14.20 = the wall breaks; the leaked pointers pin the module base and unblock the whole chain (forge dash -> arb R/W). Memory-paced: 60 probes/load, reused views, 4s+ reload delays. Beacons: V920-HIT per surviving probe, V920-BOUNDARY per crash. Zone override: ?zone=0x800000000.
