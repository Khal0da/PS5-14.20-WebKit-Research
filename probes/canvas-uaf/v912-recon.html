V912 - Pointer-derived numbers recon

Goal: find one mapped address without the canvas slot deref. V906 proved the stale wrapper derefs slot bytes as a pointer, but every blind address is unmapped and every natural candidate (V907-V911, 129 cases) crashes instead of returning a readable value. Idea: enumerate JS numbers that are derived from heap pointers or heap state (heap sizes, allocation timing, object string forms, error stacks, layout rects, event counts, ...) and beacon them in one load. If any value shows a heap-range address pattern (large 0x... hex, or a double whose bits look like a 0x0000.../0x7fff... pointer), that's the anchor — without forging a slot. No UAF trigger, no spray: pure recon, should not crash. Any SUSPECT-like hex here is a leak of which API leaks, not a slot read.
