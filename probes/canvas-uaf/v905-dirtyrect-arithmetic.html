V905 - Canvas dimension / dirty-rect arithmetic

Goal: find an OOB read/write in the canvas backing store without needing any address. No UAF, no heap grooming, no pointer knowledge: only integer/dimension arithmetic on canvas.width/height, createImageData, getImageData, putImageData dirty rects, and drawImage source rects.

One case per page load. Last stage goes to localStorage before each step, so a crash is reported on the next load as CRASH last=<case>:<stage>.
Start: ?op=auto  |  one case: ?case=dirty_neg  |  clear: ?reset=1
After a crash just reopen ?op=auto. Done when the page prints ALL CASES DONE.

Three independent detectors

1) CRASH    : last stage stored before each risky call
2) PIXELS   : canvas is pre-filled with a deterministic pattern pat(x,y,c).
              After the op every byte must be either the pattern OR the known mark
              value (0xAA). A third value = data that is not ours = OOB read leak.
3) CANARY   : 8 x Uint32Array(2048) filled 0xDEADBEEF, checked after the op.
              Any change = OOB write into live heap.
