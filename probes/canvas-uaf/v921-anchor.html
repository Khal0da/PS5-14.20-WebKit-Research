V921 - fixed anchor leak: ps_strings + argv/env + auxv

No sweep - the address is an ABI constant. On amd64 FreeBSD the process stack lives at the TOP of user space: USRSTACK = SHAREDPAGE = 0x7ffffffff000, and the kernel writes ps_strings at PS_STRINGS = USRSTACK - sizeof(struct ps_strings) = 0x7fffffffefe0 (the lowered-shared-page variant is 0x7fffffffdfe0). That page is mapped in every process, so the forged vector can read it (same primitive as V920, lineWidth = *(m_buffer + (m_size-1)*400 + 48), here with m_buffer = target-48, m_size = 1). From ps_strings the probe walks ps_argvstr / ps_envstr and the auxv table below them: AT_PHDR (main executable), AT_BASE (ld-elf), AT_ENTRY, AT_EXECPATH are real 64-bit pointers = the ASLR wall falls.
