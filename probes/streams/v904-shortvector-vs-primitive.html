V904 - tee() short-vector vs primitive-type discriminator

Question: when tee() dies, is the cause (A) the results vector ending up shorter than 2 (so results[1] is OOB), or (B) a primitive being stored/dereferenced as a JSObject?
One case per page load. No network traffic inside the iterator. Last stage is written to localStorage before every step, so after a crash the next load reports CRASH last=<case>:<stage>.

Start: ?op=auto  |  one case: ?case=obj_prim3  |  clear: ?reset=1
After a crash just reopen ?op=auto. Stop when the page prints ALL CASES DONE.

Why each case exists

ctl          normal tee(), no iterator poison                  control: MUST survive
obj2         2 plain objects                                   control: MUST survive
obj_prim3    [{a},{b},'x']  -> THE TEST                        (A) survive zLen=2 | (B) crash
o_num        new Number(1)   -> boxed, real JSObject           (A) survive | (B) survive
o_str        new String('x') -> boxed, real JSObject           (A) survive | (B) survive
o_bool       new Boolean(1)  -> boxed, real JSObject           (A) survive | (B) survive
o_fun        function(){}    -> real JSObject                  (A) survive | (B) survive
o_arr        [1,2]           -> real JSObject                  (A) survive | (B) survive
p_num        1               -> primitive                      crash both
p_undef      undefined       -> primitive                      crash both
p_str        'x'             -> primitive                      crash both
p_bool       true            -> primitive                      crash both
p_sym        Symbol('s')     -> primitive                      crash both
p_big        BigInt(10)      -> primitive                      crash both
p_str_first  ['x',{b}]       -> primitive FIRST                (A) dies at N1-ret | (B) N2-ret
p_two_prims  ['x','y']       -> both primitive                 (A) dies at N1-ret
v_getthrow   value getter throws on item #2                    protocol exception path
d_getthrow   done  getter throws on item #2                    protocol exception path

Decision rule

(A) SHORT-VECTOR   -> obj_prim3 SURVIVES with zLen=2, every boxed object survives,
                      p_str_first / p_two_prims die at N1-ret, all primitives die at N2-ret.
(B) PRIMITIVE-DEREF -> obj_prim3 CRASHES (3rd primitive is still converted),
                      boxed objects survive, primitives crash.

Native stack (optional but decisive): on the console, before re-running a crashing case, run python3 tools/send.py <PS5_IP> 9027 payloads/klog.js --arg follow --arg sec=120 --arg grep=WebProcess and look for CrashOnOverflow / Vector::at / SIGTRAP / SIGSEGV.
