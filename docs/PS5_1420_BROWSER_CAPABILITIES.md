## Implications

- **WebAudio, WebGL, WebRTC, ServiceWorker, IndexedDB, WebAssembly** are
  removed/disabled and cannot be used as attack surfaces on PS5 14.20.
- **MediaSource Extensions (MSE), Web Animations API, SVG, Shadow DOM,
  BroadcastChannel, CacheStorage, Web Workers, and Streams API** remain
  exposed and are candidate surfaces for future reconnaissance.
- The absence of WebGL is notable because many browser exploitation chains
  rely on GPU-backed memory corruption primitives; that path is closed here.
